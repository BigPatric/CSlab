# CSlab

This repository contains lab assignments for computer organization and RISC-V CPU design.

## Directory Overview

- **Lab1/**: Introductory assembly and CPU component lab (RISC-V assembly practice plus ALU/ALU control implementation).
- **Lab2/**: Single-cycle RISC-V CPU lab, including core modules and testing/submission templates.
- **Lab3/**: Basic pipelined CPU lab (pipeline stages/registers, without hazard handling).
- **Lab4/**: Advanced pipelined CPU lab with hazard detection and forwarding support.
- **Lab5/**: Cache manager lab for implementing cache read/write behavior and policies.
